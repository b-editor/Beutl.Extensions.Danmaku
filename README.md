# Beutl.Extensions.Danmaku

画面を右から左へ流れるコメント弾幕を表示するBeutlの拡張機能です。コメントはファイルからの取り込み、配信サイトからのダウンロード、手入力で用意し、要素の中に保存します。

## 使い方

1. ライブラリの「コメント弾幕」をタイムラインに追加します。オブジェクトは画面全体に描画されます。
2. プロパティパネルの「コメント」の「編集」を押します。ツールタブ「コメント弾幕」が開き、そのオブジェクトのコメントを編集できます。
3. ツールバーの「コメントを取り込む」（↓のアイコン）を押すと、タブ全体が取り込み画面に切り替わります。
   - **URL**: 動画のURLを貼り付けて「ダウンロード」を押します。
   - **ファイル**: XML・JSON・テキストのコメントファイルを読み込みます。
   - **既存のコメント**: 今のコメントと置き換えるか、今のコメントに追加するかを選びます。
   - 「履歴」には、取り込みとダウンロードが新しい順に並び、状態（取得中・完了・失敗・中止）と結果を表示します。取得中は「中止」（×のアイコン）で止められます。
   - 左上の「戻る」（←のアイコン）か Esc キーで編集に戻ります。
4. コメントの時刻は要素の先頭から数えます。動画とずれる場合はプロパティの「時刻のずれ」で調整します。
5. 要素の右クリックメニューの「オリジナルの長さに変更」で、最後のコメントが画面から消えるまでの長さにできます。

コメントはプロジェクトファイルの中に保存されるので、元のファイルを移動・削除しても表示は変わりません。コメントは要素ごとに別々に保存されます。

要素を分割すると、後半の「時刻のずれ」が分割した位置の分だけ自動で戻るので、コメントは分割前と同じ時刻に流れ続けます。動画を分割したときと同じく、前半と後半はどちらもすべてのコメントを持ちます。

## コメントの編集

ツールタブの左に一覧、右に選択したコメントの編集欄が並びます。タブの幅が狭いときは、編集欄が一覧の下に移ります。ツールバーのボタンはアイコンで、名前はツールチップに表示します。

- タブは、「編集」を押したオブジェクトだけを編集します。タイムラインの選択には追従しません。別のオブジェクトの「編集」を押すと、開いているタブがそのオブジェクトに切り替わります。
- ツールバーの「タイムラインで選択」を押すと、編集している要素をタイムラインで選択します。どの要素かはそのツールチップにも表示します。
- 編集中の要素を削除すると編集欄は隠れ、元に戻すと再び表示されます。
- タブの追加メニューには表示しません。

| 操作 | 方法 |
| --- | --- |
| 選択 | 一覧の行をクリックします。Ctrl（macOS は ⌘）や Shift を押しながらで複数選べます。 |
| 確定 | Enter キーを押すか、別の欄や別の行へ移ります。読み取れない入力は元に戻ります。 |
| 時刻 | `1:02.5` のように分:秒で入力するか、時刻の横の「再生位置にする」で今の再生位置にします。 |
| 時刻へ移動 | 時刻の横の「この時刻へ移動」を押すか、一覧の行をダブルクリックします。 |
| 位置・大きさ | 「流れる／上／下」「普通／大／小」から選びます。 |
| 色 | パレットから選ぶか、`#FF0000` のような色コードで入力します。白が既定です。 |
| 本文の改行 | Shift+Enter で改行します。一覧では「↵」で表示します。 |
| 追加・削除 | ツールバーの「追加」で再生位置にコメントを追加します。選んだ行は Delete キーかツールバーの「削除」で消せます。 |
| 絞り込み | 本文の一部を入力すると、一致する行だけを表示します。 |
| 書き出し・全削除 | ツールバーの「その他」（⋮のアイコン）から、テキスト形式（UTF-8・BOM付き）への書き出しと、すべてのコメントの削除ができます。 |

- すべての編集は、Beutlの「元に戻す」「やり直し」で戻せます。
- プロパティパネルの「コメント」には件数を表示します。

## ダウンロードできるサイト

| サイト | URLの例 | 取得方法 |
| --- | --- | --- |
| ニコニコ動画 | `https://www.nicovideo.jp/watch/sm9`、`https://nico.ms/sm9` | yt-dlp |
| YouTube | `https://www.youtube.com/watch?v=…`、`https://youtu.be/…`、`/live/…` | yt-dlp（チャットのリプレイ） |
| Twitch | `https://www.twitch.tv/videos/…` | Twitch の非公式 GraphQL API |

- ニコニコ動画とYouTubeには [yt-dlp](https://github.com/yt-dlp/yt-dlp) が必要です。yt-dlp 拡張機能がインストールした `~/.beutl/yt-dlp/yt-dlp` を優先し、なければ PATH から探します。
- ニコニコ動画のコメントは、削除済みのコメントと、ニコニコ動画の既定の共有NGフィルタで隠れるコメント（スコア -4800 以下）を除いて取り込みます。
- YouTubeで取得できるのは、生配信とプレミア公開のアーカイブのチャットだけです。配信中・配信予定の動画や、チャットのリプレイが無効な動画では取得できません。スーパーチャットは金額付きで、背景色を文字色にして取り込みます。カスタム絵文字は画像なので除きます。
- Twitchのチャットは秒単位でしか時刻がないため、同じ秒のコメントをその1秒の中に均等に散らします。長い配信では取得に数十秒かかります。
- ログインが必要な動画や、限定公開・メンバー限定の動画には対応していません。

### 利用上の注意

- コメントやチャットの著作権は投稿者にあります。取得したコメントを使った動画を公開する前に、各サイトの利用規約と投稿者の権利を確認してください。
- Twitchの取得は、TwitchのWebサイトが使う非公式のAPIを利用しています。Twitch側の変更で予告なく使えなくなることがあります。
- yt-dlp の動作はサイト側の変更に左右されます。取得できないときは yt-dlp を更新してください。

## 対応しているファイル

| 形式 | 内容 |
| --- | --- |
| XML | `<chat vpos="…" mail="…">本文</chat>` の形式。`vpos` は1/100秒単位です。 |
| JSON | `body` と `vposMs`（または `vpos` / `time`）、`commands` を持つオブジェクトを、入れ子の中からすべて探します。yt-dlp が書き出すニコニコ動画の `*.comments.json` もこの形式です。 |
| YouTubeのチャット | yt-dlp が書き出す `*.live_chat.json`（1行に1つのJSON）。 |
| テキスト | 1行に1コメントで `時刻<TAB>コマンド<TAB>本文`。カンマ区切りも使えます。 |

- テキスト形式の時刻は秒（`12.5`）か時刻表記（`1:02.50`）で書きます。コマンドの列は省略でき、本文の `\n` は改行になります。`#` で始まる行は読み飛ばします。
- 文字コードはUTF-8です。UTF-8として読めない場合はShift_JISとして読みます。

### コマンド

| 種類 | コマンド |
| --- | --- |
| 位置 | `naka`（流れる。既定）、`ue`（上に固定）、`shita`（下に固定） |
| 大きさ | `big`、`medium`（既定）、`small` |
| 色 | `white`、`red`、`pink`、`orange`、`yellow`、`green`、`cyan`、`blue`、`purple`、`black`、プレミアム色（`white2` など）、`#RRGGBB` |
| その他 | `invisible` のコメントは取り込みません。 |

## 表示のしくみ

- 流れるコメントは、投稿時刻の1秒前に右端から現れ、4秒かけて左端へ抜けます（時間は変更できます）。
- 固定コメントは投稿時刻から3秒表示し、画面より広い場合は縮小します。
- 新しいコメントは、表示中のコメントと重ならない一番上の行に入ります。流れるコメントは、前のコメントに追いつかない行だけを選びます。
- 空いている行がないときは、ランダムな高さに重ねて表示します（「あふれたコメントを表示」で切り替え）。
- 流れるコメントと固定コメントは別の層なので、互いに重なることがあります。
- 文字の大きさは、高さ384pxのプレイヤーを基準に画面の高さへ合わせます。

## 既知の制約

- フォントは和文のグリフを持つものを選んでください。既定はNoto Sans JPです。和文グリフのないフォントでは文字幅の計測がずれ、コメントが重なります。

## 開発

`Beutl.Extensibility.Sdk` 2.0.0-preview.8 でビルドします。

```bash
dotnet build src/Beutl.Extensions.Danmaku
```

```bash
dotnet test tests/Beutl.Extensions.Danmaku.Tests
```

テストには、パーサーとレイアウトの単体テスト、Beutlの `SceneRenderer` でシーンをヘッドレスに描画して画素を確認するテスト、Avaloniaのヘッドレス環境でツールタブを操作するテストがあります。描画した画像は `bin/Debug/net10.0/rendered/` に保存されます。ダウンロードのテストは偽のHTTP応答と偽の yt-dlp で動き、ネットワークを使いません。

実際のサイトから取得するテストは、URLを環境変数で渡したときだけ動きます。

```bash
BEUTL_DANMAKU_LIVE_URLS="https://www.nicovideo.jp/watch/sm9" dotnet test tests/Beutl.Extensions.Danmaku.Tests --filter LiveDownloadTests
```

Beutlにサイドロードして試す場合は、次のコマンドで `~/.beutl/sideloads` に出力します。

```bash
dotnet build src/Beutl.Extensions.Danmaku -p:DebugApplication=true
```
